お客さん

・お店の検索:店名・エリア・ジャンルで探せる
・お店ごとのページ:住所、電話、受付時間、定休日、席数、キャンセルの決まり
・空き枠からの予約:14日分の日付と人数を選ぶと、30分ごとの時間が並ぶ。満席・受付終了の時間は押せない
・予約内容の入力:電話番号、利用目的(誕生日・接待など)、ご要望(アレルギーなど)
・予約番号つきの完了画面
・予約の確認:これからの予約と過去の予約を分けて表示。お店が決めた期限までは、自分でキャンセルできる。期限を過ぎたら、お店の電話番号を案内

店舗オーナー

・店舗管理のトップ:お店ごとに、今日の予約の組数・人数・次の来店時刻
・予約台帳:日付ごとの予約一覧。「来店」「無断キャンセル」「キャンセル」の記録と、間違えたときの取り消し。1日のまとめ(組数・人数・キャンセル数)と、時間帯ごとの席の埋まり具合
・電話予約の登録:アカウントを持っていないお客さんの予約も入れられる
・予約の設定:受付時間、定休日、1組の滞在時間、Web予約の最大人数、予約の締め切り、キャンセル期限
・審査状況の確認:審査中・公開中・却下

運営

・審査待ちの店舗の承認・却下に加えて、すべての店舗の一覧と「公開を停止」

全体

・デザインのやり直し(日本語フォント、スマホ対応)
・ログイン画面の「デモ用アカウントで試す」ボタン(お客さん・オーナー・運営)
・同じ時間に2人が同時に最後の席を予約する「二重予約」を防ぐ仕組み
・デモデータを何度でも作り直せる(5店舗と、今日の前後の予約)
・まだ入っていないもの(今後の候補)
